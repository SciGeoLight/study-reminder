# 学习提醒

给手机用的学习时段闹钟。把一天的计划交进去，每个时间段开始时响铃、震动，并弹出高优先级通知。计划时间一律按北京时间。

## 安装

1. 把 `study-reminder.apk` 发到手机（微信文件、数据线、网盘都可以）。
2. 打开 APK。如果系统拦截，到设置里允许安装未知来源应用，然后再装一次。
3. 打开「学习提醒」。第一次会进入「权限检查」，把每一项点到绿色。
4. 主界面右下角加号可以手动加一条时段。旁边是「从剪贴板导入」，清单图标和「…」里的「待办」打开待办页，「…」还可以打开文件、清空这一天、5 秒后测试提醒，以及「权限检查」和「设置」。设置里的「外观」可以选浅色、深色或跟随系统。
5. 以后更新时直接安装新的 APK 即可覆盖，不用先卸载（签名密钥在仓库里，见下文）。

装好后先点「…」里的「5秒后测试提醒」，确认能听到声音、感觉到震动，锁屏时也能弹出。

## 手动添加和修改

主界面右下角加号可以加一条。选日期、开始和结束时间、标题，备注可以不写。保存后出现在那一天的列表里，到点照常提醒。

长按一条计划，可以修改日期、时间、标题和备注，也可以删除这一条。导入或同步来的计划也能改、也能删。改过之后，这条算作手动添加。下次同步或导入不会把它盖掉。如果开始时间和标题都改了，原来那一条可能会再出现一次，删掉即可。

## 外观

设置顶部的「外观」三选一：浅色、深色、跟随系统。默认跟随系统。点一下立刻换，主界面、设置、添加和修改、导入预览、权限页和全屏提醒都用同一套液态玻璃。

## 手感

按下玻璃按钮或圆形图标时，高光跟着手指，玻璃按同一套弹簧鼓起，并沿拖动方向拉伸，松开后弹回。计划卡片也是这套反馈；竖直拖动仍然滚动当天列表，横向拖动能看到拉伸。点按展开备注，长按修改或删除。

主界面大标题和顶栏中间可以左右滑动换一天，拖动时标题会带出一层玻璃。设置里的开关和「提前提醒」滑块按下会变宽，松手等数值落定再收回，拖动速度会把玻璃挤扁或拉长。全屏提醒底部的「滑动关闭」跟着手指移动。

## 导入计划

剪贴板、文件和网址同步仍然可用。再次导入只替换那一天从导入来的安排，网址同步只替换从同步来的安排。手动添加的会留下来。升级前没有来源标记的旧安排，会在下一次导入或同步时被对应操作替换。其他日期不动。

### 1. 剪贴板（最常用）

在聊天里复制下面这种纯文本，打开应用，点「从剪贴板导入」，看一遍预览，再点「确认导入」。

```
#PLAN 2026-09-27 周日安排
08:00-08:20 晨间阅读 | 读完一节就停
08:20-08:40 作业：书面练习 | 写完练习就停
21:50-22:05 收尾
```

### 2. 打开或分享文件

- 主界面右下角「…」里的「打开文件」，选 `.ics` 或 `.txt`。
- 在微信里点开文件，选「用其他应用打开」，选「学习提醒」。
- 支持日历文件（`text/calendar`、`.ics`）和上面的纯文本。

仓库里的 `samples/2026-09-27-reading.ics` 是虚构的一天（阅读、作业、散步），导入后应为 15 条，第一条北京时间 08:00。

### 3. 网址同步（可选）

自己在设置里填 URL，内容是纯文本计划或 `.ics`。点「立即同步」。填写后大约每 2 小时在有网时自动同步一次。留空则不联网。同步不会清掉手动添加的时段。同一份文件里可以加 `#TODO`。系统同时只会登记最近的 80 个闹钟，更远的存在本地，临近时再排上。同步失败不会把已经写入的计划丢掉。

## 文本格式

- 一行 `#PLAN YYYY-MM-DD 标题` 设定后面几行的日期。可以写多段，用来一次导入好几天。
- 每一条是 `HH:MM-HH:MM 标题`，后面可以用 ` | 备注`。
- 结束时间可以不写：`08:00 标题`。
- 空行忽略。
- 可以容忍全角冒号、破折号、竖线，多余空格，以及行首的 `-`。
- 标题里的中文冒号会保留，例如 `作业：书面练习`。
- 结束时间早于开始时间时，按跨到次日处理（例如 `23:50-00:10`）。

待办和计划写在同一个文件里。`#TODO` 单独成段，一行一条，用 `|` 分开：

```
#TODO
read | 阅读一章 | 2026-10-01 | 2026-10-07 | 2026-10-03 09:00 | 带着问题 | 组:阅读
walk | 去散步 | 2026-10-08 | 组:生活
hand | 交作业 | 2026-10-09
```

- 编号、标题、开始日期必填。结束日期不写就和开始同一天。
- 提醒是 `YYYY-MM-DD HH:MM`，可以不写。备注放在最后，也可以不写。
- 分组是单独一栏 `组:名字`（全角冒号 `组：名字` 也可以），放在日期、提醒或备注旁边都行。不写这一栏时，旧的四到六栏格式照旧，已经分过组的待办也不会被清掉。
- 同步第一次见到这个名字时会建一个分组。已经有同名分组就用那一个，不会改你起的名字、顺序和颜色，也不会删分组。
- 你在待办页里亲手改过某条的分组之后，以后同步只更新文字和日期，不再挪走它。
- 编号要短，不要一长串连续数字。再次同步按编号更新文字和日期，不会取消已经勾上的完成。
- 手写的待办不会被同步改掉。文件里少了一条、而且那条还没完成，同步时会删掉；已经完成的会留下。
- 没有 `#TODO` 这一段时，已有待办不动。
- 图片只存在这台手机上，不进同步。可以从相册或相机添加，原图删了也还在。

日历文件读取 `VEVENT` 的 `DTSTART`、`DTEND`（或 `DURATION`）、`SUMMARY`、`DESCRIPTION`。

- 带 `Z` 的时间按 UTC 换算成北京时间。
- 带 `TZID` 的时间按那个时区换算成北京时间。
- 没有时区的时间当作北京时间。
- 日历名 `X-WR-CALNAME` 会成为这一天的计划标题。

## 主界面

- 顶部左右箭头切换日期。不是今天时，点「回到今天」。大标题「今天」跟着列表滚走，收成顶栏中间的一行；继续往下滚时顶栏和底部按钮让开，往回滑一点或滑到末尾再出现。滚到中间时，顶栏和状态栏后面有一条背景色淡出，列表文字不会从标题底下透出来。
- 打开今天会滚到正在进行的一条，没有的话滚到下一节。点一条展开备注。
- 时间在左边，标题和备注在右边。每条计划单独一块液态玻璃，中间留出空隙，折射和「选择图片」那类按钮相同，不再铺发白的磨砂。今天正在进行的一条标「进行中」，并有进度。如果眼下没有进行中的，下一节单独标出来。已经过去的变淡。长按、修改、删除和清空都用同一块玻璃面板。全屏响铃页的时间也在玻璃里。
- 长按一条弹出「修改」和「删除」。修改可以改开始、结束、计划和备注；结束留空表示没有结束时间，写得比开始早会算到次日。删除会再确认一次。列表不再左滑删除，避免滚动时误触。清空这一天在右下角「…」菜单里。
- 「已排好 N 次未来响铃」表示闹钟已经写进系统。导入明天的计划后，这里应该大于 0。一次排进系统的不超过 80 个最近的提醒。
- 右下角清单图标或「…」里的「待办」打开待办。每条待办是一块和计划卡片相同的液态玻璃。点卡片展开或收起备注和图片，点左边圆圈才标记完成，右滑也能完成，左滑删除，长按打开修改。底部分段条和加号并排：全部、最多 3 个外露分组，最右是「…」。点「…」切换隐藏分组并设置外露。右上角「分组」仍可新建、改名、调顺序和删除。删除分组时可以选把待办移到未分组，或连待办一起删。到点提醒和计划闹钟算在同一批 80 个里。
- 到点通知上有「知道了」和「5分钟后再提醒」。提醒页上同样两个大按钮，也可以滑动关闭。响铃最长两分钟，之后通知还留在通知栏里。

默认提醒方式是「超级岛 + 悬浮通知」：到点弹出横幅，例如「08:40 开始 · 阅读：第一段」，备注在下面。然后通知栏留一条倒计时，到这个时间段结束自动消失。这条进行中通知被划掉、或点了「知道了」只关掉横幅之后，只要这段还没结束、应用还在后台，倒计时和超级岛会自己再挂上。「5分钟后再提醒」仍会先安静下来。点通知会打开当天并滚到这一条。小米、Redmi、POCO 上这条进行中通知会带澎湃 OS 焦点通知 / 超级岛参数。设置里可以改回「全屏响铃」，全屏页和循环铃声保持原样。

提前提醒在设置里，默认关闭。设置里的「背景」可以从相册选一张图，铺在主页、设置和其他页面的液态玻璃后面；「恢复默认」回到原来的渐变。照片只存在这台手机上。

## 权限清单

第一次打开，或主界面「…」菜单里的「权限检查」。

| 项目 | 做什么 | 怎样算开好 |
| --- | --- | --- |
| 通知 | 弹出提醒 | 状态为绿色。Android 13 及以上要点允许 |
| 精确闹钟 | 锁屏和省电时也准点响 | 状态为绿色。这是最重要的一项 |
| 全屏提醒 | 锁屏时直接弹出页面 | Android 14 及以上要点允许 |
| 忽略电池优化 | 避免系统推迟闹钟 | 弹窗里选允许 |
| 自启动 / 后台 | 开机后闹钟还在 | 系统无法检测。按下面品牌打开后，点「我已允许」 |

另外请把闹钟音量调高。如果闹钟音量是 0，响铃时会临时调到大约六成。

不要在系统设置里对「学习提醒」点「强行停止」。强行停止后，要再手动打开一次应用，闹钟才会重新排上。从最近任务划掉一般没关系。

手机时区请设为北京时间。计划始终按北京时间计算。

### 小米 / 红米 / 澎湃 OS

1. 权限检查里打开自启动页面。
2. 找到「学习提醒」，自启动选允许。
3. 省电策略选「无限制」。
4. 打开悬浮通知和锁屏通知。澎湃 OS 3（Android 17）同样需要这几项。
5. 从最近任务划掉没关系，但不要点「强行停止」。

### 华为 / 鸿蒙

1. 打开应用启动管理。
2. 关掉「学习提醒」的自动管理。
3. 手动打开：允许自启动、允许关联启动、允许后台活动。

### 荣耀

1. 应用启动管理里同样打开允许自启动、允许关联启动、允许后台活动。
2. 电池优化里不要限制本应用。

### OPPO / 真我 / 一加（ColorOS）

1. 自启动允许。
2. 耗电保护选「不限制」。
3. 允许后台弹出界面。

### vivo / iQOO（OriginOS）

1. 后台高耗电里允许「学习提醒」。
2. 自启动允许。
3. 权限里打开「后台弹出界面」。

### 三星

1. 电池里把「学习提醒」设为不受限制。
2. 不要让「睡眠应用」或「深度休眠」冻结它。

如果某个品牌的入口打不开，应用会退回系统的应用详情页，请在那里的电池和自启动相关菜单里允许。

## 本地编译

需要 JDK 17 或以上，以及 Android SDK（compileSdk 37，Backdrop 库要求；targetSdk 36）。

```bash
echo "sdk.dir=/你的/Android/sdk" > local.properties
./gradlew test assembleRelease
```

安装包在 `app/build/outputs/apk/release/app-release.apk`。

`versionCode` 为 24，`versionName` 为 1.7.8。界面以 1.5.0 的液态玻璃为准。待办页按 iOS 提醒事项的方式排版，每条待办用和主界面计划卡片同一套液态玻璃。点卡片展开备注和图片，点圆圈才标记完成，长按打开修改。底部分组条是「全部」加最多 3 个外露分组，最右一格是「…」。点「…」可以切到没外露的分组（含未分组）并勾选哪些分组留在底栏。深色模式选中块是亮拇指、深色字。添加和修改待办一打开就是整页。targetSdk 保持 36，这样装在 Android 17 上不会提前打开只对 target 37 生效的限制；实时活动、精确闹钟和全屏提醒按系统版本（16 及以上，含 17）启用。闹钟最多同时登记 80 个临近提醒，更远的会在到点后补上。minSdk 33，compileSdk 37。界面用 Jetpack Compose，液态玻璃来自 [Backdrop](https://kyant.gitbook.io/backdrop) `io.github.kyant0:backdrop:2.0.1`（模糊、透镜折射、色散和镜面高光）。最低 Android 13，不做更早系统的实心回退。启动图标是白描的圆弧加中心圆点，配近黑渐变底。

签名私钥不在这个公开仓库里。要打出能覆盖安装已有「学习提醒」的包，必须用同一张发布证书，证书 SHA-256 是 `e830f4dbdea35c5f2867fa1a7c7adb7e107afe424ad506d1caef320225c5ebfc`。把 `.jks` 放到 `keystore/`（该目录已被忽略），复制 `keystore.properties.example` 为 `keystore.properties` 并填入口令与别名。有这份文件时，debug 和 release 共用这把钥匙。没有它时 `./gradlew test` 仍可运行；`assembleRelease` 会拒绝打包。

## 已知限制

- 自启动没有系统接口可以检测，只能手动确认。
- 勿扰模式可能挡住声音，除非允许闹钟打断勿扰。
- 各品牌系统页面经常改名，打不开时会退回应用详情。
- 亮着屏幕时，全屏提醒通常显示成顶部横幅，这是系统行为；声音和震动仍然会来。
- 网址同步由系统安排，大约 2 小时一次，省电时可能再推迟。默认不填网址，不会联网。
- 强行停止应用后，闹钟会被系统清掉，直到再次打开应用。
- 需要 Android 13（API 33）及以上。Android 16 上折射和色散完整可用。
